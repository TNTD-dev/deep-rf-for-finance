Code snippet: Execute with VN rules

def _execute_with_vn_rules(self, t: int, target_weights: np.ndarray) -> None:
    fill_price = self._fill_price(t)  # ±7% band clamp
    pv = self._portfolio_value(t)
    target_values = np.asarray(target_weights, dtype=np.float64) * pv
    target_shares = (
        np.floor(target_values / denom / config.LOT_SIZE).astype(np.int64)
        * config.LOT_SIZE  # lot-100 rounding
    )
    delta = target_shares - self._holdings

    # Sells first to free cash
    for i in range(N_TICKERS):
        if delta[i] < 0:
            proceeds = shares * float(fill_price[i]) * (1 - config.SELL_FEE)
            self._cash += proceeds
    # Buys with affordability fallback
    for i in range(N_TICKERS):
        if delta[i] > 0:
            cost = shares * float(fill_price[i]) * (1 + config.BUY_FEE)
            if cost > self._cash + 1e-6:
                affordable_lots = int(self._cash // per_lot_cost)
                shares = max(0, affordable_lots * config.LOT_SIZE)
            self._cash -= cost

def build_graph() -> StateGraph:
    g = StateGraph(MultiAgentState)
    g.add_node("technical_analyst", technical_analyst)
    g.add_node("news_sentiment_analyst", news_sentiment_analyst)
    g.add_node("fundamental_analyst", fundamental_analyst)
    g.add_node("bullish_researcher", bullish_researcher)
    g.add_node("bearish_researcher", bearish_researcher)
    g.add_node("trader", trader)
    g.add_node("risk_manager", risk_manager)
    g.add_node("portfolio_manager", portfolio_manager)

    g.add_edge(START, "technical_analyst")
    g.add_edge("technical_analyst", "news_sentiment_analyst")
    g.add_edge("news_sentiment_analyst", "fundamental_analyst")
    g.add_edge("fundamental_analyst", "bullish_researcher")
    g.add_edge("bullish_researcher", "bearish_researcher")
    # Debate loop: bearish increments round, conditional router
    g.add_conditional_edges(
        "bearish_researcher", should_continue_debate,
        {"loop": "bullish_researcher", "exit": "trader"},
    )
    g.add_edge("trader", "risk_manager")
    g.add_edge("risk_manager", "portfolio_manager")
    g.add_edge("portfolio_manager", END)
    return g

10. Gotchas & Things That Will Bite You

1. Lookahead bias ở news timestamp

Timestamp VN thường chỉ có ngày (không có giờ). News published ngày D sẽ có timestamp = D 00:00. Nếu không gate, agent thấy tin tức TRƯỚC khi thị trường đóng cửa ngày D. Rule: news ngày D chỉ visible từ phiên D+1 close. Bake vào env layer, không patch ở callsite. Người 2 phải verify trên mỗi PR.

2. DDPG saturate tanh — underperform

DDPG policy nhanh chóng saturate ở ±1 (tanh output bound), khiến agent luôn full-buy hoặc full-sell, không học được nuance. PPO backup được train song song và dùng làm headline RL result. Đừng ngạc nhiên khi DDPG chỉ +1.1%.

3. LLM model lock — KHÔNG bypass

gpt-4o và gpt-4o-mini ONLY (cutoff Oct 2023). Test period 2025-05 → 2026-04 hoàn toàn out-of-distribution. Dùng model khác = leak future knowledge. src/llm/client.py:58 enforce whitelist bằng ValueError, không phải warning.

4. float32 precision loss ở lot-100 rounding

Action weights là float32, nhưng portfolio value ~1e9 VND. float32 × 1e9 mất ~4 VND precision/ticker → floor() đôi khi drop 1 lot. Fix: promote lên float64 trước khi tính target_shares. Xem trading_env.py:166-169.

5. BuyAndHold: giữ SHARES, không phải WEIGHTS

Nếu emit equal-weight mỗi ngày, env sẽ rebalance daily (= EqualWeightRebalance). BuyAndHold phải emit weight tương ứng với CURRENT holdings để delta_shares = 0. Dùng half-lot buffer để float32 rounding không trigger trade.

6. vnstock community tier — 4 quý gần nhất

vnstock free tier giới hạn Finance API chỉ 4 quý gần nhất. Fundamentals lịch sử 2019-2024 không khả thi. Solution: defer fundamentals sang LLM tools (fetch live tại decision time). Không fake-historical-fundamentals.

7. Multi-agent cost — ~$3 cho full backtest

8-role system × 51 weekly decisions × ~5 LLM calls/role = ~2000+ API calls. Budget ~$3-6. Nếu re-run mà không có cache, cost sẽ nhân đôi. Luôn dùng --skip-existing.

8. Z-score window trước split

Z-score normalization tính trên FULL series trước khi slice theo train/val/test. Nếu tính sau slice, rolling window sẽ cliff ở split boundary → distribution shift artifact. Xem env_data_loader.py:79.

9. Debate loop cap = 2 rounds

Bullish ↔ Bearish researcher debate có conditional edge. Nếu should_continue_debate không return đúng, loop vô hạn. Luôn có debate_rounds_max trong state và check state["debate_round"] >= state["debate_rounds_max"].

10. CORS — chỉ localhost:3000 và localhost:8000

Backend CORS chỉ allow 2 origins. Nếu chạy frontend ở port khác (e.g., 3001), request sẽ bị block. Sửa trong backend/main.py:47.

python scripts/run_all.py --skip-existing phải yield identical metrics.json trên second run. LLM agents cache theo (date, ticker_set, prompt_hash). Mọi randomness đã được seed.
